# MoviePilot 插件备份

个人自用的 MoviePilot 插件仓库，包含 5 个自建插件（作者：小罗）。可直接作为第三方插件源使用。

## 在 MoviePilot 中添加

1. 打开 MoviePilot → 设置 → 插件 → 插件市场右上角的「设置」（插件市场来源）
2. 添加仓库地址：

   ```
   https://github.com/xiaoluo-mp/MoviePilot-Local-Plugins
   ```

3. 保存后同步插件市场，在插件列表里搜索插件名即可安装或更新

| 青蛙蝌蚪福利 | `QingwaBonus` | 1.3.6 | 站点管理 | 手动购买与自动定时购买分离：自动购买可在设置中选择参与商品，详情页支持任意商品指定数量立即购买。 |

## 目录结构

```
package.v2.json          # 插件索引（名称、版本、说明、更新历史）
plugins.v2/<插件ID>/      # 各插件源码与已构建的前端产物 dist/
```
